# Level 3: Lists, Tuples, and Dictionaries

This level focuses on data structures and collection-based logic.

## Included exercises

- select item from list
- HTTP status dictionary
- count characters
- sort list
- map ports to services
- remove duplicates
- list to string experiment
- find longest word
- check dictionary credentials
- reverse string function

## Notes

This level is where the project becomes more practical and more reflective of real code patterns. It also includes a few examples that are useful for demonstrating debugging and learning refinement in a portfolio.
