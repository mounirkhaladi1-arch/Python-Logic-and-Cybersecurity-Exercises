# Level 1: Basics and Data Types

This level contains beginner exercises focused on variables, strings, arithmetic, input/output, and basic logic.

## Included exercises

- Hello hacker
- greet user
- convert string to integer
- basic calculator
- reverse string
- even/odd check
- boolean values
- binary to decimal
- alternate character case
- replace vowels

## Notes

This level is the strongest starting point for a portfolio because it shows the beginner foundations clearly and includes the binary conversion exercise, which demonstrates bitwise understanding.
