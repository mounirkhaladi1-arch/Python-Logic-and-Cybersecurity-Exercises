# Level 2: Control Flow and Loops

This level focuses on conditions, loops, and repeated logic patterns.

## Included exercises

- check password
- skip multiples of four
- print zero-padded numbers
- check leap year
- check prime numbers
- limit login attempts
- number guessing game
- fizzbuzz
- repeat until password matches
- check palindrome

## Notes

This level shows the move from simple statements into decision-making and repetition. The palindrome exercise is one of the most important examples to review carefully because it demonstrates loop logic and condition handling.
