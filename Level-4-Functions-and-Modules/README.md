# Level 4: Functions and Modules

This level introduces reusable logic, function definitions, and more structured problem-solving.

## Included exercises

- reverse string function
- check password strength
- generate random password
- hash text using MD5
- validate IPv4 address
- generate MAC address format
- character transformation experiment

## Notes

This level is a good demonstration of moving from single-purpose scripts toward more reusable logic. It is useful for showing growth in understanding as the repository progresses from beginner fundamentals to more function-based problem solving.
